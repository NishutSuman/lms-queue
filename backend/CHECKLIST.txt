IF SERVICES WON'T START:
☐ Check Docker Desktop is running
☐ Check Docker Desktop Resources (Settings > Resources)
   - Memory: at least 6GB
   - CPUs: at least 4
☐ Check port 8000 is not in use
☐ Run: docker-compose down
☐ Run: docker-compose up -d
☐ Check logs: logs.bat

IF OAUTH NOT WORKING:
☐ Check tokens.json exists
☐ Visit http://localhost:8000/test to re-authenticate
☐ Check .env has correct Google credentials
☐ Check redirect URI matches: http://localhost:8000/oauth2callback

IF WORKERS NOT PROCESSING:
☐ Check Redis: docker-compose exec redis redis-cli ping
☐ Check worker logs: logs.bat
☐ Restart workers: restart.bat
☐ Check jobs are queued in Redis

IF BROWSER AUTOMATION FAILS:
☐ Check Docker memory (need 6-8GB)
☐ Check Playwright installed: docker-compose exec api npx playwright --version
☐ Rebuild image: docker-compose build
☐ Check credentials in config.json
