# Assignment 3: AI Product Card Generator

## Objective

Create a simple web page that generates a product card using Gemini AI.

The user will enter a product idea, and Gemini will generate marketing content that will be displayed in a visually appealing card.

---

## Problem Statement

You are building a mini AI tool for startup founders.

The user enters a product idea, such as:

* Smart Water Bottle
* AI Study Assistant
* Pet Health Tracker

When the user clicks the **Generate Product Card** button, Gemini should generate:

* Product Name
* Tagline
* Short Description

The generated content should be displayed in a product card.

---

## Example

### User Input

AI Study Assistant

### AI Output

**Product Name:** StudyBuddy AI

**Tagline:** Learn Smarter, Not Harder

**Description:** An AI-powered study companion that helps students summarize notes, create quizzes, and stay organized.

---

## Requirements

### Input Section

* Text box for product idea
* Generate button

### AI Integration

Use Gemini API to generate:

* Product Name
* Tagline
* Short Description

### Product Card

Display:

* Product Name
* Tagline
* Description

Use simple CSS to make the card attractive.

---

## Bonus (Optional)

Add:

* A random emoji based on the product
* Background color change
* Copy-to-clipboard button
